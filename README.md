# DNSFrenzy
Fully automated, modular DNS switching daemon for Linux with real latency testing, IPv6/DoT support, and network-change detection.

**Installation:** `curl -fsSL https://raw.githubusercontent.com/mrcactus-afk/dnsfrenzy-linux/main/install.sh | sudo bash`
**Usage:** `sudo dnsfrenzy`
**TUI Controls:** `q` quit, `a` auto/manual, `+`/`-` delay, `l` lock, `r` refresh, `s` service, `c` config, `n` add server, `e` edit server, `d` delete server, `mouse` select.
**Uninstall:** `sudo ./uninstall.sh`
